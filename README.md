# Data Structures Using Java

A collection of Java implementations and graded exercises for learning and practicing fundamental **Data Structures and Algorithms**.

This repository is created as part of my Java programming and Data Structures learning journey. It focuses on understanding how different data structures work, how they are implemented in Java, and how they can be applied to solve programming problems.

---

## 📌 About the Project

**Data Structures Using Java** is a practice-based repository that contains Java programs and exercises related to Data Structures.

The main purpose of this repository is to:

- Understand fundamental data structure concepts
- Practice implementing data structures using Java
- Improve problem-solving and programming skills
- Understand how data is stored, organized, and accessed
- Practice algorithms and operations related to data structures
- Complete graded exercises and course-related programming tasks

## 📚 Topics Covered

This repository focuses on important Data Structures concepts, including:

### Linear Data Structures

- Arrays
- ArrayLists
- Linked Lists
- Stacks
- Queues

### Non-Linear Data Structures

- Trees
- Binary Trees
- Binary Search Trees
- Graphs

### Algorithms and Operations

- Searching
- Sorting
- Insertion
- Deletion
- Traversal
- Updating
- Iteration
- Recursion

> More topics and implementations will be added as the course and practice continue.
